# AI Universal Translator

Flask製の翻訳アプリ（テキスト／画像／音声／カメラ／チャット）。翻訳は Gemini を使います。

## 環境変数（Render の Environment に設定）
| 名前 | 内容 |
|---|---|
| `GEMINI_API_KEY` | 必須。Gemini の API キー |
| `SECRET_KEY` | 必須（render.yaml なら自動生成）。未設定だと再起動のたびに表示言語の設定が消えます |
| `GEMINI_MODEL` | 任意。既定は `gemini-4-hydrogen`。**消えたモデル名を入れると 404 で全部失敗します。AI Studio の「Get code」にあるモデル名をコピーして貼ってください** |
| `GEMINI_FALLBACK_MODEL` | 任意。既定は `gemini-3.8-flash`。混雑(503)・時間切れ・上限超過(429)・モデルが無い(404)のとき、2回目の試行でこのモデルに切り替えます。上限超過は別枠なので待たずに切り替えます（空にすると切り替えません） |
| `GEMINI_THINKING_LEVEL` | 任意。既定は `low`。翻訳に長い「思考」は不要なので下げて速くします（`off` で指定なし、`GEMINI_THINKING=1` でモデルの既定に戻す） |
| `GEMINI_TEXT_TIMEOUT` / `GEMINI_TIMEOUT` / `GEMINI_ATTEMPTS` | 任意。1回の待ち秒数（文字だけ 既定25／画像・PDF 既定40）／一時的な失敗時の試行回数（既定2）。文字の翻訳は2回試しても約50秒で終わります |
| `RATE_PER_MIN` / `DAILY_LIMIT_PER_IP` / `SITE_DAILY_LIMIT` | 任意。1分・IP別1日・サイト全体1日の上限（既定 20 / 300 / 3000）。**無料枠の1日の上限は AI Studio の「レート制限」画面で確認し、`SITE_DAILY_LIMIT` をそれより少し低く設定してください**（2026-11 時点の無料枠は、モデルごとに1分5回・1日20回。`SITE_DAILY_LIMIT=16` を設定）。上限に達した日は「今日の翻訳の枠は終わりました」と表示されます |
| `SITE_RATE_PER_MIN` | 任意。サイト全体の1分あたり上限（既定 4、0で無効）。無料枠は1モデル1分5回なので、それより少し低くしています。超えると「ただいま利用が集中しています」と表示されます。**課金を有効にしたら、この値と `SITE_DAILY_LIMIT` を上げてください** |
| `LIMIT_DAY_TZ` | 任意。既定 `America/Los_Angeles`。上限の「1日」の区切りに使うタイムゾーン。Gemini の無料枠は太平洋時間の0時（日本時間の夕方、夏時間は16時・冬時間は17時ごろ）に戻るため、それに合わせています |
| `QUOTA_SHOW_BELOW` | 任意。既定 500。`SITE_DAILY_LIMIT` がこの値以下のときだけ、画面に「今日の残り翻訳回数：あと○回」を出します（課金版で上限を大きくすると自動で非表示）。数字は `/api/quota` から取得します（利用回数には数えません） |
| `RATES_URL` / `RATES_FALLBACK_URL` / `RATES_TTL_SEC` | 任意（V12.7 通貨タブ）。為替レートの取得先（既定 `https://open.er-api.com/v6/latest/USD`）・予備の取得先（既定 Frankfurter＝欧州中央銀行。空にすると予備なし）・保存時間（既定 21600 秒＝6時間）。キー不要。**利用者が増えたら、取得元の利用条件を確認してください**（`/api/rates` は Gemini の回数には数えません） |
| `TRUSTED_PROXY_HOPS` | 任意。既定 0。IPごとの上限で使うIPの決め方です。0 は `X-Forwarded-For` の先頭（偽装されうる）、1 以上は「右から数えて N 番目」＝手前のプロキシが付けた値を使います。`ADMIN_TOKEN` を設定して `/api/stats?token=...&ip=1` を開くと、アプリが見ているIPと `X-Forwarded-For` を確認できます（自分のIPが右から何番目か確認してから設定してください） |
| `ADMIN_TOKEN` | 任意。設定すると `/api/stats?token=...` で日別の利用件数・エラー種別を確認できます |
| `KEEP_ALIVE_URL` | 任意。`https://自分のURL/healthz` を入れると10分ごとに自分を呼んでスリープを防ぎます（外部の監視サービスで /healthz を5分おきに呼ぶ方が確実） |

## 待ち時間の案内と残り回数（V12）
- 翻訳に6秒以上かかると「サーバーが起動中か、混み合っています。最大で1分ほどかかることがあります」、25秒を超えると「あと少しかかっています」を表示します（`static/js/status.js`。文言は `labels_ja.py` / `labels_en.py` の `wait_slow` / `wait_slower`）。
- 画面の上部に「今日の残り翻訳回数」を表示します（サイト全体の共有枠。`/api/quota`）。残り3回以下で黄色、0回で赤になります。
- 戻るボタンで画面が復元されたとき、「翻訳中…」のまま固まっていたボタンを自動で押せる状態に戻します。

## 画像・カメラ・PDF・単語帳（V12.5）
- **画像タブ・カメラタブの結果:** 写真の上に訳文を重ねて表示します（タップで原文）。ボタンは4つ ―「元の画像を見る／訳文を重ねる」「一覧で見る」（訳文と原文の一覧）、「拡大」（全画面。＋－ボタンかピンチで拡大、指でなぞって移動）、「画像を保存」（訳文を重ねた画像を書き出します。スマホは共有シート→「画像を保存」、PCはダウンロード）。カメラタブも画像タブと同じ部品（`templates/components/overlay_box.html`、動きは `static/js/overlay.js`）です。HEICなどで画像を保持できなかったときは、自動で一覧になります。
- カメラで撮った写真は、結果を見るあいだだけ端末（sessionStorage）に置きます。タブを閉じると消え、サーバーには保存しません。重ね翻訳では読み方（ローマ字など）は出ません（画像タブと同じ仕様）。
- **PDF翻訳:** 進捗バー（%表示。最初のページが返るまでは動き続ける表示）を出します。終わると履歴に「📄 ファイル名 (nページ)」として残り（中止・失敗した場合も、翻訳できたぶんは残ります）、履歴の訳文は先頭 4800 字までです（バックアップの上限 5000 字に収めるため。全文は画面のコピー機能で）。コードは `static/js/pdf.js`。
- **単語帳の逆引き:** 学習タブの「原文 → 訳」「訳 → 原文」で復習の向きを切り替えます。逆引きは訳を見て原文を思い出す方式で、覚えた度合い（`rbox` / `rdue`）は向きごとに別に記録します（バックアップにも入ります）。

## 言語バッジ（V12.6）
- 画像・カメラ・翻訳元「自動」の結果に出る「🌐 言語」は、「Español（スペイン語）」のように **その言語自身の名前＋いまの画面の言語での名前** で出ます（画面が英語なら「Español (Spanish)」）。名前の変換はブラウザ標準の `Intl.DisplayNames`（`static/js/display.js`）なので、41言語すべてに対応し、翻訳データは増えません。古いブラウザでは、サーバーが出す「Español (Spanish)」のままです。
- AIが英語名ではなく言語コード（`es`・`ja`・`zh-TW`・`spa` など）で返しても、`languages.py` の `normalize_language_name` が正式な言語名に直します（中国語は簡体・繁体を判別）。対応外の言語コード（`eo` など）は、画面で名前（「エスペラント語」）にします。AIへの指示にも「コードでなく英語名で」を足しました。
- 検出した言語を正しく覚えるので、`es` のときに効かなかった「検出した言語への切り替え」なども動くようになります。

## 通貨・為替（V12.7）
- 7つ目のタブ「通貨・為替」。**今日のレート**（USD基準の約160通貨）と、**いまいる国の通貨** を表示します。金額を入れると、あなたの通貨との換算ができ、よく使う通貨は一覧に追加・削除できます（端末に保存）。
- **国の判定（3段階）:** ①端末のタイムゾーン（許可不要・オフラインでも動く。`static/money/zones.json`）→ ②「現在地で判定」ボタン（GPS。端末のブラウザから直接 BigDataCloud の無料API `api.bigdatacloud.net/data/reverse-geocode-client` へ。座標は小数2桁（約1km）に丸め、TOOKIE のサーバーには送らず保存もしません）→ ③国を手動で選ぶ。通貨・国名の表示言語は `Intl.DisplayNames` で端末の言語に合わせます。
- **為替レート:** サーバー `rates.py` が open.er-api.com（キー不要・1日1回更新・表示義務あり）から取得して6時間保存し、取れなければ Frankfurter（ECB）に切り替えます。両方だめなときは前回の値を「古いかも」付きで返します。画面側も最後に取得した値を端末に保存するので、**オフラインでは最後にオンラインだったときのレートと、その時刻** を表示します。銀行間の目安であり、実際の両替レートとは異なります。
- **データの作り直し:** 国→通貨（`static/money/countries.json`）とタイムゾーン→国（`zones.json`）は `pip install babel` のうえ `python tools/build_money_data.py` で再生成できます（CLDR・IANA 由来。ブルガリアのユーロ化など、古い箇所は `OVERRIDES` で補正）。
- **V12.7.1:** 国を選ぶリストが（Windows の Edge/Chrome で）白背景に薄い文字になって読めなかったのを直しました。ディエゴガルシア島などの特殊な地域は国の一覧から外しています（`MONEY_HIDE_COUNTRIES`）。
- V13 で CSP を入れるときは、`api.bigdatacloud.net` を接続先に許可してください。

## 画面の配置（V12.8 / V12.9）
- **下のタブバーは画面の下に固定** されます（スクロールしても動きません。Instagram などと同じ）。タブは7つで、左から テキスト・画像・音声・カメラ・チャット・**通貨**・**履歴**（履歴が一番右、通貨は右から2番目）。幅は中央のカードと同じで、iPhone のホームバーの余白（`safe-area-inset-bottom`）も取ります。本文の下の余白・「元に戻す」の通知の位置は、CSS の `--nav-h`（バーの高さ）で決まります。V12.8 でヘッダーに置いた通貨ボタンは、V12.9 でバーに戻しました。
- **V12.9.1:** バーを、Instagram のような **浮いたカプセル型**（左右・下に余白、丸い角、半透明でぼかし）にしました。外側は何も受けない（`pointer-events: none`）ので、カプセルの外は後ろの内容をそのまま触れます。ボタンの数が変わっても、幅は均等に分かれます（`grid-auto-columns`）。カプセルの高さと下の余白は `--nav-h` と `--nav-gap`。設定の最後に **版の名前**（例：`TOOKIE V12.9.1`）を出し、応答に `X-App-Version` ヘッダーを付けました。ページ（HTML）には `Cache-Control: no-cache` を付け、古いページと新しい CSS/JS が混ざらないようにしています。版を上げるときは `app.py` の `APP_VERSION` を変えます。
- スマホで文字を入力しているあいだ（キーボードが出るあいだ）は、バーを隠します（`static/js/app.js`。パソコンや、プルダウンの選択では隠しません）。
- プライバシーのリンクは、バーの外（本文の末尾）にあります。バーはトップページだけで、オフライン画面・プライバシー画面にはありません。
- **V12.9 の直し（スマホで重なる・はみ出す所）:** 通貨タブの「あなたの通貨」のプルダウンが枠からはみ出していたのを直しました（`min-width: 0`）。換算の「から」「へ」は上下2段にして、右に入れ替えボタンを置きます（通貨名が切れないように）。通貨の選択肢の文字は「JPY 日本円」に短くしました。ヘッダーは、幅380px未満で言語ボタンをアイコンだけにし、ロゴとの間にすき間を付けました。
- **配置のテスト:** `python tests/e2e_v129.py` は、390・360・320px の日本語・英語で、全タブの横はみ出し・ヘッダーの重なり・バーの文字の切れを測ります。Tailwind の CDN が使えないので、手元で作った CSS（`tests/fixtures/tailwind-local.css`。作り直しは `tools/build_test_tailwind.mjs`）を差し込みます。テスト専用で、本番は CDN のままです。

## ファイル構成（V12.10〜V12.11）
動きは変えず、長かったファイルを役割ごとに分けました（URL・関数名・`translator.xxx` で使っていた名前は同じです）。V12.11 では、日本語・英語の画面文言と、通貨・画像重ね表示のJSも分けました。

| ファイル | 役割 |
|---|---|
| `app.py` | アプリの起動・セキュリティヘッダー・版の名前（`APP_VERSION`） |
| `routes/pages.py` | 画面（トップ・言語選択・言語の切り替え）とフォームの翻訳 |
| `routes/api_translate.py` | 翻訳の API（文字・PDF・別の言い方・解説） |
| `routes/pwa.py` | ホーム画面に追加（PWA）・オフライン（manifest / Service Worker / オフライン画面） |
| `routes/system.py` | 全データ削除・プライバシー・利用状況・残り回数・為替レート・ヘルスチェック |
| `translator.py` | Gemini の呼び出し・再試行・予備モデルへの切り替え・各翻訳の組み立て・PDF |
| `prompts.py` | Gemini に渡す指示文（システムプロンプト）と丁寧さの指定 |
| `gemini_errors.py` | `TranslationError` と、例外・応答をエラーの種類に分ける処理 |
| `json_reply.py` | Gemini が返した JSON の読み取り・検査 |
| `languages.py` | 言語表（名前・コード・RTL）と `get_ui_labels`（画面文言を取り出す。`UI_LABELS` は従来どおりここから使えます） |
| `labels_ja.py` / `labels_en.py` | 日本語・英語の画面文言（手書き。以前は `languages.py` の中にありました） |
| `helpers.py` / `limits.py` / `rates.py` / `ui_i18n.py` / `phrasebook.py` | 共通の部品・利用制限・為替・画面文言の生成・フレーズ集 |
| `static/js/money.js` `money_start.js` `money_where.js` `money_view.js` | 通貨タブ: 定数と整形 / 起動とレート取得 / 現在地と国の選択 / 換算・一覧・検索の表示 |
| `static/js/overlay.js` `overlay_zoom.js` `overlay_save.js` `overlay_boot.js` | 画像の重ね表示: 縮小と重ね表示 / 拡大 / 画像として保存 / 送信前の処理と起動時の復元 |

`translator.py` に残してあるもの（呼び出し・再試行・PDF の読み取り）は、テストが差し替えて動作を確かめている部分です。これを別ファイルにするときは、テストの差し替え先も一緒に直す必要があります。`tests/test_v1210.py` が、URL の一覧と公開名が分ける前と同じことを、`tests/test_v1211.py` が、画面文言の中身・JSの読み込み順・名前の重複がないことを確かめます。

JSは、`templates/components/scripts.html`（と `offline.html`）に書いた順に読み込みます。同じ名前の関数や `const` を別ファイルに作ると画面全体が止まるので、`test_v1211.py` が重複を検出します。

## v1.2 の変更（口調の切り替え・長文の要約）
- **口調を変える**（結果カードの「…」メニュー）: 1回の API 呼び出しで、**丁寧・標準・くだけた**の3つの訳を受け取り、選んだものに訳を置き換えます（履歴も同じ内容になります。読み方は、新しい訳に合わないので消えます）。3つそろわない結果のときは、失敗として扱い、今の訳はそのままです。設定の「丁寧さ」は、最初の翻訳の口調を決めるものとして、そのまま残っています。
- **要約**: 原文が **600文字以上**のとき、結果カードに「要約する」ボタンが出ます（`helpers.SUMMARY_MIN_CHARS`）。**押したときだけ** API を呼び、いまの画面の言語で、3〜5個の箇条書きにします。
- どちらも、サイト全体の利用制限・1日の上限・`/api/stats` の集計（`tone:` `summary:`）の対象です。
- 新しい文言は5つです（`tone_btn` `tone_label` `tone_neutral` `summary_btn` `summary_label`）。日本語・英語は手書きで入っています。**他の39言語は、v1.3 のあとにまとめて `tools/generate_ui_labels.py` で生成します**（それまでは英語で表示されます）。

## v1.4 の変更（翻訳スタイル・解説の拡張）
- **翻訳スタイルが7つに**（設定 →「翻訳スタイル」）: 自動／自然な会話／直訳／丁寧／ビジネス／くだけた／スラング。選んだスタイルは、文字・画像・PDF・別の言い方・会話のすべての翻訳に効きます。保存済みの設定（自動・丁寧・くだけた）は、そのまま使えます。
- 結果カードの「…」→ **「ニュアンス・使い方を解説」**: 意味・スラングに加えて、使う場面、失礼に聞こえないか、友人・同僚・目上のどれに合うか、地域による違いを説明します。外国語の文を読んだときは原文を、自分の言語で入力したときは、相手に言う訳文のほうを解説します。
- 新しい画面の文言は6つ（ja/en のみ。他の言語は `python tools/generate_ui_labels.py` で作ります）。
- ブラウザでの確認は `python tests/e2e_v140.py` です。
- 要約はすでに箇条書き（3〜5個）なので、変更はありません。

## v1.5 の変更（画像・カメラ・単位変換）
- **画像の文字を、タップで選んで翻訳**（画像タブ・カメラタブ）: 読み取り（API 1回）のあと、画像の上に文字のまとまりごとの枠が出ます。タップで選ぶ／外す、「すべて選択」「選択を解除」。下のパネルに、選んだ部分の原文と訳が出ます（何も選ばなければ全部）。選び直しでは API を使いません。
- **「即翻訳」**: 選んだ部分だけを、画像の上で訳文に置き換えます。何も選ばずに押すと、全部を置き換えます。もう一度押すと元の画像に戻ります。訳文を置き換えた枠をタップすると、その部分だけ元に戻ります。拡大表示・画像の保存・コピーも、選んだ部分（無ければ全部）にかかります。一覧ボタンは、常に下に出るパネルになりました。
- **全画面のカメラ**: 「カメラ」タブを押すと、画面全体のカメラに切り替わります。左上の矢印でもとの画面へ。下に大きな撮影ボタンと、アルバムから選ぶボタン。ライト（フラッシュ）は、対応する端末（主に Android）だけに出ます。撮影・アルバムの写真は、そのまま翻訳へ進みます。`static/js/camera_full.js`
- **単位変換**（通貨タブの中）: 長さ・重さ・温度・体積・面積。計算は端末の中だけで、API は使わず、オフラインでも使えます。`static/js/units.js`
- 新しい画面の文言は13個（ja/en のみ。他の言語は `python tools/generate_ui_labels.py` で作ります）。
- ブラウザでの確認は `python tests/e2e_v150.py` です。

## 画面の多言語化
- 日本語・英語は `labels_ja.py` / `labels_en.py` に手書き（`languages.UI_LABELS` で取り出せます）。それ以外は `ui_labels/<言語コード>.json` を読みます。
- 足りない文言がある言語は、スタート画面で選んだ時に Gemini が足りない分だけ自動翻訳して保存します（失敗したら、その分は英語で表示）。
  Render の無料枠はディスクが消えるため、**事前に作ってコミット**しておきます（そうすると、選んだときに API を使いません）。
- 差し込み記号（`{h}` `{g}` など）が原文と違う翻訳は、画面に記号が出てしまうので使わず、英語で表示します。

```powershell
python tools/generate_ui_labels.py --check     # API を使わず、どの言語がどれだけ足りないか確認
python tools/generate_ui_labels.py             # 足りない文言だけ作る（途中で止まっても、次は続きから）。最初に「混雑チェック」を1回だけ試す
# 実行すると「APIキーを貼り付けて Enter」と聞かれる。貼り付けても画面には何も出ない（それで正しい）。キーは保存されない
git add -A ; git commit -m "Add UI labels" ; git push origin main
```
- 無料枠は「**Google のプロジェクトごと・モデルごとに** 1分5回・1日20回」程度です。**同じプロジェクトでキーを作り直しても、枠は増えません。** ツールは、本当の呼び出し1回ごとに約13秒待ち、**失敗した呼び出しも数えて**、1回の実行で使う回数に上限（既定15回。`--max-calls 10` で変更）を付けています。1日の上限か、この回数に達したら、保存済みの分を残して止まります。**日本時間の夕方（17時ごろ）に上限が戻る**ので、そのあとにもう一度同じコマンドを実行してください。全39言語（日本語・英語以外）が揃うまで、数日かかることがあります。
- **同じプロジェクトのキーを使うと、公開中のサイトと同じ枠を使います（文言づくりで使い切ると、サイトが「今日の枠は終わりました」になります）。** 文言づくりには、AI Studio で「新しいプロジェクト」を作ってそこで取ったキーを使うと、サイトの枠を減らしません。課金版に切り替えれば、数分で終わります。
- **混雑チェック（v1.0.4〜）:** 本番の前に、ごく短い依頼を1回だけ試します。Google が混んでいれば、そこで止まります（使う呼び出しは1〜2回だけ。終了コード 3）。1日の枠をむだにしないための仕組みです。この1回も、実行の上限（`--max-calls`）に数えます。省くときは `--no-check`。
- 文言は文字数が多いので、ツールの中だけ待ち時間を150秒にしています（アプリ本体は25秒のまま）。時間切れのときは40個ずつの小分けでやり直し、Google 側の混雑（503）のときは間を空けて1回だけ再挑戦します。**2言語続けて失敗したら、混んでいるとみて止まります**（作れた分は残るので、1〜2時間おいて、もう一度同じコマンドを実行してください。昼〜夕方のほうが通りやすい傾向があります）。止まったときは、理由（混雑／今日の枠の上限／この実行の上限／キーの問題）に合わせた次の手順が画面に出ます。
- **APIキーは、ツールに聞かれたときだけ入力します（画面には出ず、保存もされません）。コマンドの文字や引用符の中にキーを書かないでください。画面のコピーやログを人に送る前に、キーが写っていないか確認してください。** 万一見せてしまったら、AI Studio でそのキーを削除（無効化）して新しいキーに替え、Render の `GEMINI_API_KEY` も新しいキーに更新します。
- 作り直したい言語は `--force --only Thai`（英語名）。生成された JSON は母語話者に確認してもらい、直接編集して構いません。`From` / `To` は全言語で固定です。

## AI学習（スラング・省略語への対応）
モデルの再学習ではなく、翻訳のたびに次を Gemini に渡して精度を上げています（すべて端末内に保存）。
- 直近のチャットの流れ（文脈）
- 用語集（設定タブ → 用語集）
- 訳を直した内容（修正例。直近3件を手本として送信）

## Render の起動コマンド
サービスを Docker ではなく Python（Native）で作った場合は、Settings → Start Command を次にしてください（既定の `gunicorn app:app` は待ち時間が30秒で、Geminiが遅いとサーバーが落ちて「Internal Server Error」になります）。
```
gunicorn -w 1 --threads 8 --timeout 120 -b 0.0.0.0:$PORT app:app
```
（`Dockerfile` を使う場合は同じ内容がすでに入っています）


## データの保存とバックアップ
履歴・お気に入り・用語集・単語帳・チャットは、各自のブラウザ（localStorage）にだけ保存されます。設定タブ →「設定」の下の「データ」で次の操作ができます。
- バックアップの書き出し（JSON。iPhoneは共有シートから「ファイルに保存」）／読み込み（今のデータに追加。重複はまとめます）
- 端末のデータと設定をすべて削除（ゴミ箱の中身も含めて完全に消えます。こちらは元に戻せません）
- ブラウザに保存データの永続化を依頼（Safariが長期間使われないサイトのデータを消すのを防ぐ。許可は端末次第）

## ゴミ箱（元に戻せる削除）
- 履歴・用語集・単語帳・チャットを消すと、すぐには消えず「ゴミ箱」（設定タブ →「ゴミ箱」）に **30日間** 残ります。消した直後は画面下に［元に戻す］が出ます。
- ゴミ箱からは「元に戻す」「完全に削除」「ゴミ箱を空にする」ができます。30日たつと自動で消えます。
- ゴミ箱はこの端末の中だけ（バックアップの書き出しには含みません）。

## ホーム画面に追加（PWA）とオフライン
- iPhone: Safari で開き、共有ボタン →「ホーム画面に追加」。アプリのように全画面で起動します（設定タブ →「データ」にも案内あり）。
- 通信できないときは、自動で「オフライン画面」（`/offline`）が開きます。履歴・お気に入り・用語集・フレーズ集・バックアップの書き出しが使えます。**翻訳そのものにはインターネットが必要です。**
- 画面の部品（JS/CSS/アイコン/フレーズ集）は Service Worker（`/sw.js`）が端末に保存します。デプロイして内容が変わると版番号が変わり、古い保存は自動で消えます。
- Tailwind・FontAwesome は外部CDNなので、**初回にオンラインで一度開いておく**と、以後オフラインでも見た目が崩れません。
- Service Worker は https（または localhost）でだけ動きます。

## v1.0 の公開前チェック（アプリ化の前に）
1. **画面文言が全言語そろっているか:** `python tools/generate_ui_labels.py --check` が「全言語が揃っています」と出る（上の「画面の多言語化」）。
2. **`google-genai` の版を固定する（v1.0.4 で完了）:** Render のログの起動行 `[startup] TOOKIE V… / google-genai X.Y.Z / ...` で版を確認し、`requirements.txt` を `google-genai>=3.6,<4` にしました（Render に入っていたのは 3.6.1）。次の大きな版（4.x）に上げるときは、テストと翻訳の動作を確かめてから。
3. **`TRUSTED_PROXY_HOPS` を決める:** 既定の 0 は、`X-Forwarded-For` の先頭（利用者が偽装できる値）をIPとして使います。`ADMIN_TOKEN` を設定し、`/api/stats?token=...&ip=1` を開いて、`seen_ip` が自分のIPか、`x_forwarded_for` の右から何番目が自分のIPかを確認してから設定します（右端なら 1、Cloudflare などが挟まって右から2番目なら 2）。間違えるとIP別の上限が全員共通になるので、確認してから。
4. **`Dockerfile`:** `render.yaml` が `env: docker` なので必要です。消さないでください（Python（Native）で動かしている場合も、害はありません）。
5. **最終テスト:** `python -m pytest tests -q` と、上の e2e をすべて流す。
6. **タグとバックアップ:** `git tag v1.0-pre-app` → `git push origin v1.0-pre-app`。フォルダ全体を zip にして別の場所（クラウドなど）に置きます（`.git` を含めると履歴ごと戻せます）。

## 無料枠から課金版へ切り替えるとき
コードは変えずに、環境変数だけで切り替えられます。
1. AI Studio で、このプロジェクトの請求を有効にする（予算アラートも設定する）
2. Render の Environment で、`SITE_DAILY_LIMIT` と `SITE_RATE_PER_MIN`（必要なら `RATE_PER_MIN`）を上げる
3. 保存すると自動で再デプロイされる

## セキュリティ
- 全ページに `X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy` / `Permissions-Policy` / `Strict-Transport-Security` を付けています。
- CSP（読み込みを許可する場所の制限）は、外部の CDN（Tailwind / FontAwesome）を外す V13 で入れます。
- `requirements.txt` は、次の大きな版の手前に上限を付けています。
